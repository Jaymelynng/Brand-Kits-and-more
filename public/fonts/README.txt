Font sources: https://github.com/google/fonts

Barlow Condensed Bold is the unmodified static font from ofl/barlowcondensed.
DM Sans Regular is a static instance of DMSans[opsz,wght].ttf at weight 400,
optical size 14. Fredoka SemiBold is a static instance of Fredoka[wdth,wght].ttf
at weight 600, width 100. The latter two were instantiated with fontTools.
These files retain their original copyrights and SIL Open Font License 1.1.
Each family folder contains its own OFL.txt. Keep that license with its font.
